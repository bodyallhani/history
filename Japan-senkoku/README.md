# 전국시대 지도

1575년 말, 1582년 말, 1600년 세키가하라 직전, 1601년 말을 비교하는 한국어 대화형 지도입니다.

지도를 열려면 `index.html`을 브라우저에서 여세요. 현대 배경지도는 인터넷 연결이 필요합니다. 지도·세력권·가문·전투 표시를 켜고 끌 수 있고, 가문을 검색하거나 시대별 거점 이동을 살펴볼 수 있습니다.

전체 192개 가문·계통·지역 공동체를 수록했습니다. 시점별 표식은 127개, 107개, 111개, 95개입니다. 영토 색칠은 16세기 경계를 정밀하게 복원한 자료가 아니라 주요 세력권의 **개략도**입니다. 작은 가문은 주로 거점으로 표시합니다. 성 표식과 좌표도 성터의 정확한 발굴 경계가 아닌 대표 위치입니다.

당주는 확인된 시점의 인물만 이름을 표시하고 나머지는 `미확인`으로 둡니다. 기존 데이터에서 넘어온 일부 인명에는 `재검토 필요`가 붙습니다. 문장은 Wikimedia Commons에서 해당 가문과 연결된 도안을 확인한 일부 계통만 표시합니다. 현대 벡터 도안은 당시 실제 깃발·의복의 색과 형태를 보증하지 않습니다. 자료가 없는 계통에 문장을 임의로 그리지 않았습니다. 도안 출처·제작자·라이선스는 해당 가문 상세 정보의 링크에서 볼 수 있습니다. 개별 기록은 `atlas-data.json`에도 있습니다.

현대 해안선은 [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)의 public domain 자료를 사용했습니다. 현대 지도는 [OpenFreeMap](https://openfreemap.org/) 및 [OpenStreetMap](https://www.openstreetmap.org/copyright) 기반입니다. 지도 엔진인 [MapLibre GL JS 4.7.1](https://github.com/maplibre/maplibre-gl-js/blob/v4.7.1/LICENSE.txt)은 3-Clause BSD 라이선스입니다. 일본 역사 지도와 연표 자료의 링크는 앱의 ‘자료 안내’와 각 가문 상세 정보에 있습니다.
